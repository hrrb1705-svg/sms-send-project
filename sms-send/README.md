# sms-send

برنامه اندروید برای:

- خواندن فایل Excel با چهار ستون
- ارسال پیامک با سیم‌کارت گوشی
- ثبت پاسخ‌های دریافتی در همان فایل

## ساختار فایل Excel

ستون‌ها باید به ترتیب زیر باشند:

1. تلفن
2. متن پیام
3. پاسخ
4. وضعیت

هنگام ارسال، برای هر ردیف ابتدا وضعیت `در انتظار نتیجه ارسال` ثبت می‌شود و بعد از بازگشت نتیجه ارسال، همان ردیف به `ارسال موفق` یا پیام خطا به‌روزرسانی می‌شود.

## منطق پاسخ‌ها

- شماره فرستنده پیامک دریافتی قبل از ذخیره نرمال‌سازی می‌شود.
- دکمه دریافت پاسخ، آمار ردیف‌های به‌روزشده را در `AlertDialog` نشان می‌دهد.
- تطبیق پاسخ‌ها با شماره‌های فایل بر اساس `normalizePhone` انجام می‌شود.

## نکته‌ها

- فرمت فایل باید `.xlsx` باشد.
- این نسخه تا حد امکان وابستگی خارجی ندارد و خواندن/نوشتن XLSX را با کد داخلی انجام می‌دهد.
- انتخاب فایل از طریق File Picker انجام می‌شود و نیاز به دسترسی مستقیم به حافظه ندارد.
- برای ارسال و دریافت پیامک باید مجوزهای پیامک در گوشی تأیید شوند.

## ساخت در Termux

این پروژه `gradlew` ندارد. بنابراین ساخت محلی با Termux به‌صورت مستقیم از ریشه پروژه انجام نمی‌شود و باید از GitHub Actions یا یک محیط Android Gradle کامل استفاده شود.

## ساخت در GitHub

در این پروژه یک Workflow برای GitHub Actions هم قرار داده شده است:

- با هر `push` به شاخه اصلی، APK دیباگ ساخته می‌شود.
- فایل خروجی در بخش Artifacts قابل دانلود است.
