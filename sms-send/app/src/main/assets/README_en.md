User guide produced by Hamid Reza Rahimi with the help of AI

This app is built to send bulk SMS messages from an Excel file.

The Excel file must have fourteen columns. Column one is the user name, column two is the mobile number, column three is the message text, and column four shows the received reply and column five shows the status or error. In the first row of the file, the title row, columns six through fourteen can hold nine ready-made phrases that correspond to the digits one through nine.

Follow these steps to use the app.

First, press the select file button at the bottom of the screen and choose the Excel file from the phone's storage. After selecting it, the file's contents are shown on screen as a table, and this same button becomes the update file button. Whenever you press it again later, the file is read fresh and the table is shown updated.

Second, in the message text column of each row, either write your own custom text, or type just a single digit from one to nine. If you type a digit, the app sends that person the matching ready-made phrase you wrote in the first row's columns six through fourteen, instead of the digit.

Third, press the send messages button. The app checks every row. If the message text column holds a text or a digit from one to nine and it has not been sent yet, the app sends it. As soon as a row's send is confirmed successful, the send date and time replaces the text in that same message column.

If the message text column holds a date, the app looks in the phone's inbox to see whether a message from that same number arrived after that date. Only replies that are exactly one digit from one to nine are accepted, in Persian or English digits. If there are several valid replies, the most recent one counts. In that case the reply digit is written in column four, the ready-made phrase matching that digit is sent to that person, and once the send is confirmed the new date replaces the old one. If no new valid reply has arrived, the row stays unchanged. A row whose mobile number or message text is empty is skipped with no error shown.

For this to work, the app asks for permission to send and read SMS the first time you send.

The date and time that replaces the message text is the phone's own clock at the moment the phone confirms the send. It is not the time the message reached the recipient's inbox. The table on screen also refreshes automatically after each send is confirmed.

An important note about mobile numbers: to avoid any errors, please enter mobile numbers using English digits, not Persian digits.

The settings button at the top of the screen opens a window where you can choose the app's language between Persian and English, and changing the language switches all the buttons and the guide to that language.

This same help button shows this text at any time.
